#  Modul Land Cover (Tutupan Lahan)

Dokumentasi untuk modul tutupan dan penggunaan lahan (LULC - Land Use / Land Cover):
- **Sumber Data**: Esri Sentinel-2 10m Land Cover / Klasifikasi Tutupan Lahan Indonesia.
- **Kategori Lahan**: Hutan (Tree Cover), Semak Belukar (Shrubland), Pertanian (Crops), Permukiman (Built Area), Badan Air (Water), dll.

---

##  Rencana Pembahasan
1. Klasifikasi Kelas Tutupan Lahan.
2. Integrasi Layer Spasial & Titik Sampel.
3. Hubungan Tutupan Lahan terhadap Karakteristik dan Kerentanan Kebakaran.
4. Optimalisasi Performa Query Spasial.
