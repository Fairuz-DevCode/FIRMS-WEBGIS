#  Modul Peatland (Ekosistem Lahan Gambut)

Dokumentasi untuk modul pemetaan dan analisis ekosistem lahan gambut Indonesia:
- **Sumber Data**: Peta Kubah Gambut & Kesatuan Hidrologis Gambut (KHG) Kementerian Lingkungan Hidup dan Kehutanan (KLHK).
- **Atribut Ekologis**: Kedalaman Gambut, Tingkat Kematangan (Saprik, Hemik, Fibrik), Status Kerentanan dan Zonasi Lindung/Budidaya.

---

##  Rencana Pembahasan
1. Struktur Poligon & Multipolygon PostGIS (`peatlands`).
2. Spatial Intersection: Deteksi Kebakaran di Lahan Gambut vs Non-Gambut (`ST_Intersects`).
3. Analisis Forensik Kebakaran di Kubah Gambut (Peat Fire Behavior & Smoldering).
4. Penilaian Risiko Kerusakan Ekologis Gambut.
